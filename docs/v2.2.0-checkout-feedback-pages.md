# v2.2.0 – Checkout Feedback Pages & User Profile

## Overview

Adds post-payment feedback pages and a user-facing order history page so customers know whether their purchase succeeded or failed.

---

## New Pages

### `/order-success` — `OrderSuccess.page.tsx`
Shown after a successful Stripe payment. Displays:
- Order ID (returned by the backend)
- Payment Intent ID (Stripe reference)
- Total amount charged
- Customer name
- Links to "View My Orders" (`/my-profile`) and "Continue Shopping"

State is passed via React Router `navigate(..., { state })` from the checkout form; no extra API call is needed.

### `/order-failure` — `OrderFailure.page.tsx`
Shown when any step of the payment process fails (Stripe card error, incomplete payment, or server error). Displays:
- Error code (e.g. `card_declined`, `payment_incomplete`, `server_error`)
- Human-readable error message
- Links to "Try Again" (`/shipping-address`) and "Back to Cart" (`/my-cart`)

**The cart is NOT cleared on failure** — the user can return to the cart and retry without losing their items.

### `/my-profile` — `UserProfile.page.tsx`
Authenticated-only page showing:
- User avatar, name, and email (from Auth0)
- Full order history fetched from `GET /orders/my-orders`
- Each order shows: Order ID, status badge (confirmed/pending/processing/failed), order date, total amount, and Stripe payment reference

## Cart Behaviour

| Scenario | Cart State |
|----------|-----------|
| Payment succeeds, order saved | Cart cleared (localStorage + Zustand) |
| Stripe card error | Cart preserved |
| Payment not `succeeded` status | Cart preserved |
| Server/API error saving order | Cart preserved |
