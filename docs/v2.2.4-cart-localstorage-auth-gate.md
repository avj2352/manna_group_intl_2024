# v2.2.4 — Shopping Cart localStorage Sync, Auth Gate, and Checkout Prefill

## Summary

Three improvements to the shopping cart and checkout flow:

1. **Real-time cart badge** — adding or deleting items updates the navbar badge count instantly, without a page refresh.
2. **Login deferred to Checkout** — users can browse and fill the cart without being prompted to log in. The login dialog only appears when they click the "Checkout" button and are not yet authenticated.
3. **Checkout form prefill** — the Full Name field is prefilled with the Auth0 user's name when the user is logged in.

---

## Files Changed

### `ui/src/hooks/use-localstorage.ts`

Rewrote the hook to propagate changes in real time:

- `setStoredValue` is now a stable function (no longer `useState` setter) that writes to `localStorage` and fires a `CustomEvent` (`manna-ls-update:<key>`).
- Every hook instance subscribed to the same key listens for that event and re-reads from `localStorage`, so all components (Navbar badge, ShoppingCart page) update simultaneously without needing a shared Zustand action.
- The native `storage` event listener handles cross-tab sync.

### `ui/src/pages/checkout/ShoppingCart.page.tsx`

- Removed the `useState(!isAuthenticated)` dialog that opened the login prompt on every page load.
- Added `handleCheckout()` — navigates to `/shipping-address` if logged in, otherwise opens the login dialog.
- Fixed a bug in `populateCartInventory` where `acc.map(x => x.count += 1)` incremented the count on **all** items instead of only the matching one.
- `handleDeleteCartItem` now reconstructs the flat localStorage array by repeating each item `count` times, preserving correct quantity after deletion.
- The `useEffect` on `storedValue` now also calls `setCheckoutCount` so the badge stays in sync when items are deleted from the cart page.

### `ui/src/pages/checkout/AddressShipping.page.tsx`

- Added a `useEffect` in `CheckoutForm` that hydrates `cart_items` from `localStorage` on direct navigation or page refresh (when Zustand state is empty).
- Added `useAuth0()` in `CheckoutForm` to read `auth0User.name` and prefill the form's `name` field via `react-hook-form`'s `reset()`.
- The page wrapper (`AddressShippingPage`) now redirects unauthenticated users to `/my-cart` (where the login dialog appears) instead of silently calling `loginWithRedirect()`.

## Behaviour Before / After

| Scenario | Before | After |
|---|---|---|
| Open shopping cart (not logged in) | Login dialog shown immediately | Cart shown freely; no prompt |
| Click Checkout (not logged in) | — (dialog was already open) | Login dialog appears |
| Add item to cart | Badge updates only after page reload in some paths | Badge updates instantly |
| Delete item from cart page | Badge could lag | Badge updates instantly |
| Checkout form (logged in) | Name field blank | Name prefilled from Auth0 profile |
| Navigate to `/shipping-address` directly (not logged in) | Silent redirect to Auth0 login | Redirect to `/my-cart` with login prompt |
